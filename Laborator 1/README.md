# City Explorer

Mini-site de prezentare a unor destinații turistice, realizat în cadrul disciplinei Tehnologii Web.

Ca să așez elementele corect în pagină, m-am folosit de Flexbox la meniul de navigare și de CSS Grid pentru ca lista de carduri cu destinații să se adapteze automat în funcție de mărimea ecranului.

Am adăugat o secțiune de recomandări și un formular simplu pentru planificarea excursiilor.
